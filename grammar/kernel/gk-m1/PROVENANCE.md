## Annotation method

Initial coordinates were visually selected from the extracted embedded rasters using normalized grid and pixel-grid inspection. This is an **assistant proposal**, not human validation.

The binding file records both source-pixel and normalized geometry so a human validator can reproduce, adjust, accept, or reject each proposal.

## Epistemic classification

- Source-image identity and dimensions: **measurement / provenance**
- Proposed primitive locations: **observation candidate** pending human validation
- Geometry functions: **deterministic measurement method**
- Any manuscript-wide grammar/function claim: **not established by GK-M1**
