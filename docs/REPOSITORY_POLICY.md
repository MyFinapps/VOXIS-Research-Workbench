# Repository Policy

## Commit here

- source code
- JSON schemas and registries
- experiment definitions and small fixtures
- provenance metadata/hashes
- tests and validation notes
- WebXR static source and selected runtime assets
- Unity source/config required to reproduce prototypes

## Keep in external/local research archive

- full manuscript/source PDFs
- raw photographs
- long videos
- large rendered media
- large 3D binary assets
- build outputs and generated caches

Use Git LFS only when a specific reproducibility need justifies versioning a large binary artifact.
