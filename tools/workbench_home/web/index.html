Help & recovery

Connect your instruments

Choose Configure and paste the full path. For Browser and Bridge, choose the existing Start-Record launcher or its Python file. Home runs the same Python entry point. Stem Lab uses its HTML file. WXR uses its HTTPS address. Resonance uses its existing Python, Windows executable, batch or PowerShell launcher.

Understand the status

Configured means the location is saved. Running means Home still tracks the launcher; it does not certify the instrument. Browser additionally responds to a local readiness check. Declared versions are not independently verified.

A window did not open?

Use the session link shown after launch if your browser blocks a new tab. For Stem Lab, open the configured HTML file directly. Check launcher windows for errors, missing dependencies or occupied ports. Home never installs dependencies or stops another process to free a port.

Restart without duplicates

Home remembers launches after restart. If it says Check existing session, close the instrument and its launcher, then Configure → confirm it is closed → Clear launch reminder. A failed launch may also leave a reminder. Never clear it while the instrument is still running.

Close & back up

Use each instrument’s own shutdown control. Close Home stops only Home; closing its tab does not stop Home. Before copying the Bridge index, close Browser, Bridge and any other index user. Keep the live index local, outside sync folders. Preserve the current copy before restoring a known-good backup. Test restoration using a disposable copy and Bridge Verify index first.

Home configuration

Only local locations, entry-file hashes, declared versions and launch reminders are saved. Session tokens are not saved. To recover a damaged configuration, close Home, preserve the file and restore a known-good copy; no automatic repair is attempted.

Current limits

Home 0.1 is a candidate awaiting Forge integration acceptance. Native recall and cross-engine replay are not implemented. Opening WXR on desktop does not verify Quest behavior.

Close Workbench Home?

Your instruments remain separate. Stop each one in its own window when you finish.
