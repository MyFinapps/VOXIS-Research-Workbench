# EX-GRAMMAR-001 — Historical Selected-Case Pipeline Test

**Status:** INVALIDATED BY BINDING DEFECT — retained for provenance, not evidence

EX-GRAMMAR-001 preregistered and executed a selected 2v `STEM → POINT → Y` measurement as an end-to-end pipeline test.

During EX-GRAMMAR-002A Stage A blind candidate-inventory construction, close inspection of the original `VM.f2v` raster showed that both source annotations used by EX-GRAMMAR-001 were visibly offset from the intended botanical structures. Therefore the deterministic numerical output is reproducible as a computation over those coordinates, but the coordinates themselves are not accepted as adequate primitive geometry.

The original result and canonical event are retained and explicitly flagged `invalidated_by_binding_defect`. They may not be used as evidence, recurrence support, or IF state input.

A corrected historical comparison, if run, must use a new result/event identifier after corrected geometry receives human validation.
